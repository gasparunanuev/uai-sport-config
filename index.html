Configuración en 4 pasos
1
Acceso GitHub
Conecta esta app con tu cuenta de GitHub
⌄
💡 ¿Para qué sirve este paso? Esta app necesita un token para poder guardar tus cambios (reservas, sesión) directamente en GitHub desde tu teléfono. El token se queda guardado solo en este dispositivo, nunca se envía a ningún servidor externo.

→ Crear token en GitHub (2 min)

2
Mis Reservas
Qué deporte, a qué hora y qué días reservar
⌄
💡 ¿Para qué sirve este paso? Aquí defines tu horario deportivo. El bot buscará exactamente ese deporte y esa hora en el intranet, y reservará automáticamente cuando se abran los cupos (cada día a las 20:00). Puedes agregar múltiples deportes.
3
Renovar Sesión
Actualizar acceso al intranet UAI cuando expire
⌄
💡 ¿Para qué sirve este paso? El bot accede al intranet UAI con tu sesión de Microsoft (cookies). Esta sesión dura ~90 días. Cuando venza, recibirás una notificación de alerta — aquí podrás renovarla en 2 minutos desde tu teléfono, sin computador.
Cómo renovar cuando el bot te avise
1
Abre Safari y entra al intranet
Ve a intranet.uai.cl e inicia sesión con Microsoft. Completa el código de autenticación si te lo pide.
2
Activa el marcador "Capturar Cookies"
Una vez dentro del intranet, toca ese favorito en Safari. Verás un JSON con tus cookies de sesión.
3
Copia todo el JSON y pégalo abajo
Toca "Copiar" en la ventana que abre el marcador, luego pega el texto en el cuadro de abajo.
4
Toca "Actualizar Sesión"
Las cookies se cifran automáticamente con criptografía y se suben al servidor. El bot queda listo.
📌 Instalar marcador "Capturar Cookies" (una vez)
En Safari iPhone: guarda cualquier página como favorito → luego edita ese favorito → borra la URL y reemplázala con el código JavaScript de abajo.
